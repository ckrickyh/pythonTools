**Overview**

Welcome to my project! This repository features a Python script that automates the process of uploading photos from Google Drive to Airtable, specifically for tree surveys. As a dedicated bootcamp student transitioning from an arboricultural background to the tech industry, I am passionate about leveraging technology to solve practical challenges.

Motivation

My journey into the tech field is driven by a desire to create impactful solutions. While conducting tree surveys, I realized that Airtable, despite its user-friendly interface, lacks the ability to automatically upload images based on specific identifiers. This inspired me to develop a script that simplifies this workflow, enhancing efficiency in data management.

Features
Automated Uploads: Effortlessly upload photos from Google Drive to Airtable.
Customizable: Easily modify the script for various projects or data types.
User-Friendly: Designed to be accessible for both beginners and experienced developers.
